## Принятые решения

### Имя и адрес

Проект переименован из Orbit в **«Перигей»** (латиницей `perigee`).
Перигей — ближайшая точка орбиты, момент максимального сближения двух тел:
ровно то, что делает главная анимация.

Прод — **`https://perigee.awwwdde.art`**, slug проекта в панели `perigee`.
Папка репозитория на диске осталась `svidanie` — это ни на что не влияет.

### Дизайн — редизайн внедрён

Первая версия делалась строго по разделу 5 ТЗ (тёмная база `#0B0A0F`,
холодные акценты) и была признана скучной. Заказчик сделал свой макет
в Claude Design — **«Тёплая ночь и одна орбита»**, он внедрён целиком.

Исходник: [USE_DESIGN.md](USE_DESIGN.md), проект
`2e5d14b3-71a2-4309-b75c-ed27ff529954`, читается через `DesignSync`.

**Что изменилось:**

- **Тёплый уголь вместо холодного.** `coal #0B0908`, `surface #161210`,
  `surface2 #211B18`, `stroke #332A26`.
- **Новый токен `linen #C4B9B0`** — абзацы и длинный текст. `mist` теперь
  только подписи и метки.
- **Цвета людей переосмыслены:** `ember #FF7A5C` (было `#FF4D4D`),
  `iris #8FA0FF` (было `#7B5CFF`). Равная светлота L≈0.78 и различие
  тёплый/холодный, а не «красный против фиолетового» — читается и при
  дальтонизме. `lime #C8FF6A` не тронут.
- **Появилась светлая тема.** Раньше приложение было только тёмным.
  На светлом свечение не работает: глубина строится тенями, сферы теряют
  половину блюра и падают до opacity .35.
- **Типографика крупнее и реже:** body 16 → 17/26 (16 остаётся жёстким
  минимумом для инпутов), трекинг display −0.02 → −0.03em, у label
  0.08 → 0.14em. Поля экрана 20 → 24px.
- **Новые радиусы:** `tile 20px` (плитка, фото места), `cell 14px`
  (ячейка календаря).
- **Сферы получили общую орбиту.** Раньше они дрейфовали каждая сама
  по себе и «сближение» приходилось угадывать. Теперь обе сидят на
  кольце в 1px: чем ближе точки на кольце, тем ближе свидание. Состояние
  `pulling` переименовано в `drawing`, добавлен светлый мост между сферами.
  Кольцо подсвечивается lime только в состоянии `merged`.

**Как устроено технически.** Цвета заданы CSS-переменными в
`styles/index.css`, Tailwind ссылается на них (`coal: 'var(--coal)'`).
Одни и те же имена работают в обеих темах, значения переключаются в
`@media (prefers-color-scheme: light)`. Поэтому **жёсткие hex в компонентах
запрещены**: `PERSON_HEX` заменён на `PERSON_VAR` со ссылками на переменные,
иначе цвет человека не переключится вместе с темой.

Старый `components/orb/Orb.tsx` удалён — его заменил `OrbField`.

**Экраны перекомпонованы под макет** (разделы 03–05), а не просто перекрашены:

- **Главный** — вариант «сфера-герой»: отсчёт живёт внутри слитой сферы,
  дата самый крупный элемент, `lime` ровно дважды (чип и обводка кольца).
  Пустое состояние переписано: «Подозрительно тихо. Кто-то же должен начать».
- **Карточка свидания** — дата в две строки (`splitDate`), сверху обрезанная
  сфера цвета автора, подпись «Задумал(а) Влад · подтверждено 6 августа».
- **История** — группировка по месяцам моно-заголовком, полоса автора
  4px без свечения: в списке важнее ритм, чем эффект.

- **Мастер создания** — плейсхолдер поиска «Кофе, выставка, скамейка…»,
  карточка места с моно-чипом источника (без иконок: одинаково читается
  для kudago/osm/2gis/custom), свои места обводятся цветом человека.
  Счётчик записки молчит до 240 символов. Шаг 5 — предпросмотр той самой
  карточки, которую увидит второй, а не сводка полей.
- **Настройки** — мини-сфера вместо аватара: цвет человека и есть его лицо.
  Крестик отзыва 44px, но визуально тихий.
- **Онбординг** — тексты из макета, поле кода моно 19px в зоне 60px,
  экран «Десять ключей» с чекбоксом «Сохранил, честное слово»: кнопка
  «Готово» до него неактивна. Единственное место, где мы что-то требуем.

**Не перекомпоновано:** раздел 06 (приглашение) — это Фаза 6, экрана ещё
нет; раздел 07 (движение словами) — спецификация анимаций, не прочитан.

**Кнопка «Отправить приглашение» на шаге 5 не сделана намеренно** — она
появится в Фазе 6 вместе с токенами. Сейчас последний шаг сохраняет
черновик.

### Отклонения от ТЗ (все осознанные)

1. **Redis не используется** — панель даёт гостю только Postgres.
   Challenge WebAuthn и кэш мест живут в Postgres. Подробности в DEPLOY.md.
2. **Security-заголовки ставит приложение** — маршрут гостя в Caddy идёт
   голым `reverse_proxy`, заголовков от него не будет.
3. **Две таблицы сверх схемы ТЗ 10:** `refresh_tokens` (без неё не сделать
   отзыв цепочки из ТЗ 9.6) и `webauthn_challenges` (замена Redis).
4. **`GET /api/auth/me` сверх таблицы ТЗ 11** — access-токен живёт только в
   памяти JS, после перезагрузки имя и цвет надо спросить у сервера.
5. **py_webauthn 3.0** вместо 2.x из ТЗ — актуальный мажор, набор функций тот же.
6. **`disallow_any_explicit` в mypy выключен** — конфликтует с плагином
   pydantic. `--strict`, который требует ТЗ, включён полностью.

## Что проверено вживую

**Фаза 1.** `docker compose up` поднимает стек одной командой. Прод-образ
собирается, `/healthz` отвечает той же командой, которой его дёргает панель,
deep link рендерится, CSP/HSTS/nosniff на месте, ключей API в бандле нет,
traversal закрыт.

**Фаза 2.**
- Миграция `0001_auth` проходит цикл up → down → up (в даунгрейд пришлось
  дописать удаление enum-типов — автогенерация их не удаляет).
- CLI: заведены Влад и Ангелина, выдача инвайтов работает, повтор отвергается.
- 19 смоук-проверок API: CSRF-заголовок, неверный/верный инвайт,
  `residentKey=required`, `userVerification=required`, `platform`,
  httpOnly-cookie challenge, пустой `allowCredentials`, rate limit 429,
  401 без сессии.
- Ротация refresh: нормальный обмен, повторное использование даёт
  «скомпрометирована» и **гасит всю цепочку** — новый токен тоже мёртв.
- Авторизованные эндпоинты живым токеном: `/auth/me` → Влад/ember,
  `/auth/devices` → `[]`, `/auth/devices/invite` → код на 10 минут.
- Фронт: `RequireAuth` уводит с `/` на `/onboarding`, шаги онбординга
  переключаются, поле ввода 16px, все зоны нажатия ≥44px, ошибок в консоли нет.
- Сквозной путь браузер → прокси Vite → контейнер API → Postgres:
  `/register/options` возвращает опции с `rp.name = "Перигей"`.
- Сферы: у обеих бесконечные yoyo-твины 19с и 23с, GSAP в отдельном
  ленивом чанке 27.8 КБ.
- `mypy --strict` и `tsc --noEmit` чисты.

**Фаза 3.**
- Сборка выдаёт `sw.js`, `workbox-*.js` и `manifest.webmanifest`;
  precache 25 файлов. Манифест с кириллическим именем и `maskable`-иконкой.
- Сервер отдаёт `sw.js` и манифест с `Cache-Control: no-cache` — иначе
  обновление не доедет (ТЗ 17).
- Шлюз standalone: во вкладке показывается экран установки вместо
  приложения; **`/i/:token` проходит мимо шлюза** (иначе сломался бы
  сценарий ТЗ 2.3, где второй просто открывает ссылку).
- Детекция standalone работает обоими путями: `display-mode: standalone`
  и легаси `navigator.standalone` в Safari.
- Иконки генерируются скриптом `npm run icons` (Pillow, только локально,
  в зависимости проекта не входит). Сфера в maskable умещается в
  центральные 80%.
- Не-телефоны получают заглушку (`app/DeviceGate.tsx`): проверены десктоп
  с мышью, планшет с тачем и телефон.
- Бандл 142 КБ gzip.

**Фаза 4.**
- 26 сквозных проверок API: создание, права, правка, отмена, удаление, места.
- **Найден и закрыт баг:** черновик утекал гостю через прямой URL. В списке
  фильтр стоял верно, а на путь «по id» правило не распространялось —
  второй участник числится гостем и проходил проверку участника. Теперь
  черновик виден только автору, остальным 404 (не 403: сам факт, что
  вторая половина что-то готовит, тоже часть сюрприза).
- Календарь: 126 ячеек (три месяца в DOM), высота ячейки ровно 44px,
  прошедшие дни заблокированы, «сегодня» определяется по Москве.
- Барабан времени: `scroll-snap-type: y mandatory`, 24 часа, шаг 5 минут.
- Таймзона: 19:00 в Москве → `16:00Z` на сервер и обратно 19:00. Зимой
  тоже +3 — в России нет перехода на летнее время.
- Главный экран: `lime` применён **только** к статусу «Подтверждено»,
  отсчёт «17 д 2 ч», сферы в состоянии `merged`.
- Лента: полоса автора `rgb(255,77,77)` — цвет Влада.

## Отладка в браузере на ПК (временный режим)

Чтобы гонять сценарии, не устанавливая приложение и не имея биометрии,
в **dev-сборке** включены три послабления. Все три физически отсутствуют
в проде, это проверено `grep` по `dist/`.

| Что | Где | Как отключается на проде |
|---|---|---|
| Экран установки не показывается | `app/StandaloneGate.tsx` | ветка под `import.meta.env.DEV`, Vite её вырезает |
| Заглушка не-телефона смотрит только на ширину | `app/DeviceGate.tsx` | то же; в проде остаётся проверка `pointer: coarse` |
| Кнопки «Войти как Влад / Ангелина» | `lib/auth/devLogin.ts` + онбординг | то же |
| Эндпоинт `POST /api/auth/dev-login` | `routers/auth.py` | регистрируется только при `DEV_AUTH_ENABLED`, а `config.py` **не даёт стартовать** с этим флагом на HTTPS-домене |

Порядок работы: `docker compose up`, открыть http://localhost:5173,
включить в F12 эмуляцию телефона (или просто сузить окно < 600px),
нажать «Войти как Влад».

**Перед выкладкой на прод ничего убирать вручную не нужно** — но и
`DEV_AUTH_ENABLED` в переменные проекта на панели добавлять нельзя:
приложение откажется подниматься.

## Баги живого тестирования (исправлены)

### Второй заход

4. **Сохранённый черновик нельзя было отправить.** Кнопка отправки жила
   только на последнем шаге мастера — из карточки свидания её не было,
   и черновик оставался мёртвым грузом. Добавлена «Отправить приглашение»
   на карточку.

5. **Ссылка терялась навсегда.** `POST /dates/{id}/send` на уже
   отправленном отвечал 409, а сама ссылка нигде не сохранялась: закрыл
   share-sheet — и отправить приглашение больше нечем. Теперь повторный
   вызов отдаёт **ту же ссылку** (не создаёт новую), а на карточке она
   остаётся на экране с кнопкой «Скопировать».

6. **Ожидающее приглашение не было видно на главной.** Экран показывал
   только подтверждённые, и «отправил, а дальше тишина» выглядело так,
   будто ничего не произошло. Добавлено состояние «Ждём ответа» — с ним
   наконец используется состояние сфер `drawing` из ТЗ 5.4.

7. **«Не удалось загрузить ленту» показывалось поверх данных.** При
   неудачном фоновом обновлении React Query оставляет прежние данные,
   а баннер всё равно рисовался. Теперь ошибка видна, только если
   показывать больше нечего.

### Первый заход

1. **Календарь показывал меньше трети дней.** Лента шириной в три экрана,
   а месяц внутри был размечен `w-full` — то есть 100% **ленты**, а не
   экрана: 981px вместо 327px. Большая часть дней уезжала за край, и
   выбрать дату в текущем месяце было нельзя. Теперь ширина месяца
   передаётся числом в px. **Никогда не использовать `w-full` внутри
   ленты, которая шире вьюпорта.**

2. **Не пройти опросник приглашения.** `AnimatePresence mode="wait"`
   монтирует следующий кадр только после того, как доиграет exit
   предыдущего. Если анимация не завершилась — свёрнутая вкладка,
   throttling rAF, — человек застревал навсегда и до кнопки «Иду!»
   не добирался. Переведено на `mode="popLayout"` и здесь, и в мастере
   создания. **Правило: декоративная анимация не должна преграждать
   функциональный путь.** Заодно пять условных слотов внутри
   `AnimatePresence` заменены на одного ребёнка с меняющимся `key` —
   это канонический паттерн, массив из `false` там ломкий.

3. **Кнопка «Дальше» уходила на 8.5 экранов вниз.** На шаге «Где»
   60 карточек мест давали страницу в 6934px, и продолжить было нельзя,
   даже выбрав первое место. Панель действий сделана липкой
   (`sticky bottom-0`), фон непрозрачный без блюра — на длинном списке
   `backdrop-filter` роняет FPS (ТЗ 5.3).

## Грабли окружения (сэкономят время)

- **Docker Desktop не стартует сам.**
  `Start-Process "$env:ProgramFiles\Docker\Docker\Docker Desktop.exe"`,
  затем `until docker info >/dev/null 2>&1; do sleep 3; done`.
- **Панель Browser не отображается → страница не композитит кадры.**
  `requestAnimationFrame` не срабатывает вообще, `visibilityState: hidden`,
  поэтому **GSAP-анимации выглядят замершими**. Это не баг: логику твинов
  проверять через `gsap.getTweensOf(el)` и `tween.progress(p)`, импортируя
  gsap **тем же URL с `?v=`**, что и приложение (иначе получите второй
  экземпляр с пустым таймлайном).
- **Vite из `preview_start` недоступен** из шелла и из `navigate`. Обход:
  `npx vite --host 127.0.0.1 --port 5199`. Если `preview_start` уже запущен,
  он перехватывает вкладку — сначала `preview_stop`.
- **Новые Python-пакеты добавлять в `api/pyproject.toml`**, а не только в
  локальный venv: контейнер соберётся без них и упадёт на импорте.
- **Смена `POSTGRES_USER` требует пересоздания тома** — Postgres заводит
  пользователя только при первой инициализации (`docker compose down -v`).
- **`TestClient` использовать только как контекстный менеджер**
  (`with TestClient(app) as c:`), иначе на каждый запрос новый event loop,
  а пул asyncpg остаётся на закрытом → `Event loop is closed`.
- **`exactOptionalPropertyTypes: true`**: опциональные пропсы, которым может
  прилететь `undefined`, объявлять как `foo?: string | undefined`.
- Локальный venv в `api/.venv` (Python 3.13; в образе — 3.12).

## Фаза 5: что сделано и что сломано

### Яндекс отпал

Платный: **195 000 ₽**. Бесплатен только JavaScript API (100 запросов/сутки),
но он не подходит: это сторонний скрипт в приватном приложении (запрещено
ТЗ 20), он ослабляет CSP (ТЗ 16) и ломает серверный агрегатор — искать
в браузере и сводить с серверными источниками негде.

**Решение: KudaGo + OpenStreetMap**, оба бесплатны и без ключей. 2ГИС —
опционально за фича-флагом. `yandex` оставлен в enum `place_source` на
случай, если ключ однажды появится.

### Написано и лежит в репозитории

```
app/schemas/places.py               PlaceDTO, PlaceQuery, Schedule
app/services/places/categories.py   12 категорий + маппинг рубрик
app/services/places/base.py         протокол PlacesProvider
app/services/places/osm.py          Overpass
app/services/places/kudago.py       события + площадки
app/services/places/twogis.py       за фича-флагом
app/services/places/aggregator.py   параллельный опрос, дедуп, сортировка
app/services/places/cache.py        кэш в Postgres
app/services/places/registry.py     полный цикл поиска
app/db/models/places_cache.py       таблица кэша
alembic/versions/0003_places.py     миграция (цикл up/down/up проверен)
```

Роутер: `/api/places/search`, `/api/places/categories`,
`/api/places/{source}/{external_id}`. Маршрут деталей объявлен **последним**
намеренно — иначе `{source}/{external_id:path}` перехватывал бы `/custom`.

### Работает

- KudaGo отдаёт 60 мест с фотографиями за ~1с.
- Кэш: повторный запрос — **0.01с** вместо 6с.
- Падение провайдера не ломает поиск: когда OSM выпал, выдача пришла
  из KudaGo (это критерий приёмки ТЗ 19).

### Разделение труда между источниками

Противоречие с OSM решено так: **текст ищет KudaGo, категории — OSM.**

Фильтровать по названию на стороне Overpass слишком дорого (регулярка по
`name` стоила 7.6с против 4.0с без неё), а фильтровать локально нечем —
сервер отдаёт лишь `out center 40`, и до фильтра доходят случайные сорок
заведений. Поднять лимит нельзя: на 300 и 800 публичный Overpass отвечает
504. Поэтому `OsmProvider.search()` при непустом `query.q` сразу возвращает
пустой список, а текстовый поиск целиком берёт на себя KudaGo с его
`/search/`.

Overpass остаётся best-effort: публичный инстанс отдаёт 504 при частых
запросах. Агрегатор его падение переживает, это проверено.

### Что проверено вживую

- **Текст «выставка»:** 1.1с, 60 результатов, **30 событий с датами на
  позициях 1–6**. До правок было 2 события в самом хвосте.
- **Категория «Кофе»:** 2.2с, **ответили оба источника** (`kudago`, `osm`),
  100 результатов, кофейни OSM отсортированы по расстоянию от 309 м.
- **Кэш:** повторный запрос 0.01с вместо 6с.
- **Падение провайдера не ломает поиск** — критерий приёмки ТЗ 19.
- **UI шага «Где»:** 8 категорий, 62 карточки, **свои места первыми**
  («Наша скамейка», «Дома с пиццей»), у карточек значок источника,
  категория, расстояние и адрес. При вводе текста категории скрываются.
- Ошибок в консоли нет. `mypy --strict` и `tsc --noEmit` чисты.

### Два бага, найденных и закрытых

1. **Идущие выставки теряли даты.** `_parse_daterange` брал только `start`,
   а у открывшейся в прошлом выставки он прошедший — дата отбрасывалась,
   и событие выглядело обычным местом. Теперь учитываются `end`,
   `is_endless` и `is_startless` (у последних KudaGo ставит началом первый
   год нашей эры).
2. **События тонули в хвосте выдачи.** В поиске у них приходит только
   `{"id": …}` без координат, а сортировка считала отсутствие расстояния
   бесконечностью. Теперь место без координат считается «где-то в середине
   радиуса» — иначе выставки, ради которых KudaGo и нужен, никто бы
   не увидел.

### Замеры, которые стоит помнить

| Что | Было | Стало |
|---|---|---|
| KudaGo events с `expand=place,dates` | 9.9с | 1.1с без `expand` |
| Overpass с регуляркой по `name` | 7.6с + битый JSON | 4.0с без неё |

- **`/places/?q=` в KudaGo молча игнорируется** — выдача с ним и без него
  идентична. Текстовый поиск умеет только `/search/?ctype=place`, но у него
  беднее поля: нет фотографий и рубрик.
- **KudaGo отдаёт все даты повторяющегося события**, включая 2018 год.
  Отфильтровано до будущих.
- **`PROVIDER_TIMEOUT` поднят с 3с до 6с** вопреки ТЗ 12.3: три секунды
  писались под платный Яндекс, бесплатному Overpass нужно ~4с. Цена разовая,
  дальше отвечает кэш.

## Деплой на прод

Можно и нужно: вход по Face ID и установка на домашний экран проверяются
только на реальном HTTPS-домене.

**В env-переменных проекта на панели — ничего обязательного.**
`DATABASE_URL`, `PUBLIC_SITE_URL`, `SECRET_KEY`, `JWT_SECRET` панель ставит
сама, остальное имеет рабочие значения по умолчанию.

**Категорически нельзя добавлять:**
- `DEV_AUTH_ENABLED` — приложение не стартует (защита от обхода входа);
- `RP_ID` — выводится из домена, ручное значение рискует убить passkey.

**У панели нет терминала**, поэтому CLI на проде выполнить негде.
Пользователи и первый инвайт заводятся переменными окружения проекта —
`BOOTSTRAP_USERS` и `BOOTSTRAP_INVITES` (см. DEPLOY.md). Приложение
создаёт их на старте, идемпотентно. Инвайт самоотключается, как только
у человека появляется passkey — проверено.

Локально те же люди заводятся через CLI:

```bash
docker exec perigee_app python -m app.cli create-user --username vlad --display-name "Влад" --color ember
docker exec perigee_app python -m app.cli create-user --username angelina --display-name "Ангелина" --color iris
docker exec perigee_app python -m app.cli issue-invite --username vlad
docker exec perigee_app python -m app.cli issue-invite --username angelina
```

⚠️ **Первый passkey, созданный на проде, намертво привяжет домен
`perigee.awwwdde.art`.** Убедиться, что адрес окончательный, до ввода кода
на телефоне.

Локальные инвайт-коды (только для `localhost`, до 4 августа 13:52 UTC):
Влад `AVJY-SUMH-4G8P`, Ангелина `QBR4-SECY-W9M7`. Договорились сбросить и
перевыпустить после следующего обновления.

## Правила проекта (не забыть)

- TypeScript `strict`, `any` запрещён везде, включая тесты.
- Python: полная аннотация, `mypy --strict` без ошибок.
- **Никаких TODO-заглушек.** Не реализуемо — остановиться и спросить.
- Каждая новая зависимость обоснована. UI-киты, библиотеки календарей,
  moment.js, axios, Redux — не ставить. Календарь пишется руками.
- Дисциплина цвета: `lime` = только «подтверждено», больше нигде.
  `ember`/`iris` — цвета людей (Влад / Ангелина), не украшение.
- **Все новые страницы делаются по макету «Тёплая ночь и одна орбита»**
  ([USE_DESIGN.md](USE_DESIGN.md)) — это указание заказчика. Прежде чем
  верстать новый экран, прочитать соответствующий раздел макета через
  `DesignSync`, а не изобретать композицию заново.
- Цвета только через CSS-переменные (`PERSON_VAR`, токены Tailwind).
  Жёсткий hex в компоненте не переключится вместе со светлой темой.
- Один DOM-узел анимируется одной библиотекой: сферы — GSAP,
  React-дерево — Framer Motion, Lenis только инерция скролла.
