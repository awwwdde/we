# Что вписать в панели awwwdde

Проект: **`perigee`** → `https://perigee.awwwdde.art`

---

## Переменные окружения проекта

Скопируйте эти пять строк в env-переменные проекта в админке панели.

```
BOOTSTRAP_USERS=vlad:Влад:ember,angelina:Ангелина:iris
BOOTSTRAP_INVITES=vlad:3HQD-DXK6-M9TT,angelina:7ZRZ-ZGKT-PWUK
VAPID_PUBLIC_KEY=BCc-k5xBjQp4zZzaXeLpSfSqDQk_oA8VM4fJjKv4YflZAwrdjhmUC4lqRFa4E6twQ4u-fIWNYUV8SIANkE1Tic4
VAPID_PRIVATE_KEY=_rsEPRisbCUXTlbRwUwUIF4HX7yfxmcVgrXkeuKIvvs
VAPID_SUBJECT=mailto:admin@awwwdde.art
```

Всё остальное — `DATABASE_URL`, `PUBLIC_SITE_URL`, `SECRET_KEY`,
`JWT_SECRET` — панель проставляет сама, вписывать не нужно.

### Что делает каждая

| Переменная | Зачем |
|---|---|
| `BOOTSTRAP_USERS` | создаёт Влада и Ангелину на старте контейнера — терминала в панели нет, иначе завести их негде |
| `BOOTSTRAP_INVITES` | одноразовые коды для первого входа; **перестают работать сами**, как только у человека появляется passkey |
| `VAPID_*` | уведомления. Без них приложение работает, просто молчит |

Коды в `BOOTSTRAP_INVITES` можете заменить на свои — не короче 8 символов.

## Чего добавлять НЕЛЬЗЯ

| Переменная | Что будет |
|---|---|
| `DEV_AUTH_ENABLED` | **приложение не запустится.** Это обход входа без passkey, на боевом домене он запрещён намеренно |
| `RP_ID` | выводится из домена автоматически. Ручное значение рискует навсегда сломать все passkey |

## Порядок первого запуска

1. Вписать переменные выше, задеплоить.
2. Проверить: `curl -i https://perigee.awwwdde.art/healthz` → `200`.
3. Открыть сайт **на телефоне**, поставить на домашний экран.
4. Запустить **с иконки**, а не из браузера — иначе не сработают ни
   passkey, ни уведомления.
5. «У меня код приглашения» → ввести свой код → Face ID.
6. **Сохранить 10 кодов восстановления.** Показываются один раз, и это
   единственный способ войти, если телефон потеряется.
7. Настройки → «Включить уведомления» → «Проверить».

## Важные предупреждения

**Первый созданный passkey намертво привязывает домен.** `RP_ID` вшивается
в ключ навсегда: после этого сменить `perigee.awwwdde.art` нельзя, не убив
все passkey. Убедитесь, что адрес окончательный.

**Смена ключей VAPID обнуляет все подписки** — уведомления придётся
включать заново на каждом устройстве. Менять их без причины не нужно.

**Уведомления на iPhone** работают только с iOS 16.4+ и только для
приложения, запущенного с домашнего экрана. В браузерной вкладке подписка
не создаётся вовсе — это ограничение Apple, а не приложения.

**Данные переживают редеплой.** Панель пересоздаёт только контейнер
приложения; база `perigee_db` живёт в своём томе. Passkey, свидания
и подписки остаются. Единственное, что их удалит, — удаление проекта
с галкой «удалить данные».
